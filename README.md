# react-native-ivs-player

Amazon Ivs player for react native

## Installation

```sh
npm install react-native-ivs-player
```

## Usage


```js
import { IvsPlayer } from "react-native-ivs-player";

// ...

<IvsPlayer />
```

## How to publish a new version


```sh
yarn prepare
yarn release
npm publish
```
